# Onboarding checklist

Copy this list into your onboarding ticket. Your manager signs off each block.

## Week one

- [ ] Read [Day one](day-one.md) and can state the three rules.
- [ ] LLM gateway development key issued and used once.
- [ ] Knowledge base, Confluence `AIKB` and Jira `AIKB` access confirmed.
- [ ] Workstation set up on the paved-road Python stack; secret-scanner hook installed.
- [ ] Tutorials 1 and 5 completed.
- [ ] Owners of your team's areas met; one FAQ proposal submitted.

## Day 30

- [ ] One change shipped on a paved road with an evaluation.
- [ ] Can read gateway logs for your own requests.
- [ ] Model owners for all team models known.

## Day 60

- [ ] Led one review using the code review skill.
- [ ] Evaluation set written or improved; trend visible on the dashboard.
- [ ] One knowledge-base finding raised through the review process.

## Day 90

- [ ] One page, skill or tutorial contributed and in use by another team.
- [ ] Model risk pre-assessment completed for a real or mock use case.
- [ ] Paired with a newer joiner on their first week.

## For the manager

- [ ] Access issues, tooling gaps and missing documentation filed against the knowledge
      base (Jira project `AIKB`, label `onboarding-gap`).
