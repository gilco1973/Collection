# Day one

## Before lunch: the three rules

1. **No customer data leaves approved systems.** Prompts, files and logs that contain
   customer or employee data go only through the [LLM gateway](../paved-roads/llm-gateway.md).
   Never paste such data into a consumer AI tool. See [data classification](../best-practices/data-classification.md).
2. **AI output is a draft until a human owns it.** Code, analysis and customer-facing text
   generated by a model are reviewed by an accountable person before use.
3. **Every model in production has a model owner and a risk record.** If you cannot name
   both, the model is not in production. See [model risk](../governance/model-risk.md).

## Set up your workstation

- Python 3.11 with Poetry (the paved-road Python stack).
- The internal SDK bundle for the LLM gateway (see [tutorial 1](../tutorials/01-first-call.md)).
- Pre-commit hooks that run the secret scanner. Commits containing credentials are rejected.
