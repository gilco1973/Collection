# Onboarding

Welcome. This section is the path from "first day" to "shipping AI features on the paved
roads" for anyone joining a team that builds, reviews or operates AI in the bank.

## How to use this section

1. [Day one](day-one.md) — access, tools, the three rules you must know before lunch.
2. [First week](first-week.md) — read the paved roads, run the first tutorial, meet the owners.
3. [30 / 60 / 90 days](30-60-90.md) — what "productive" looks like at each milestone.
4. [Reading list](reading-list.md) — ordered, with why each item matters here.
5. [Checklist](checklist.md) — the sign-off list you and your manager complete.

Already on a team and asked to be its AI champion? Start with [the programme](ai-champions.md) and the
[initiative brief](ai-champions-initiative-brief.md).

## Adapting this knowledge base to your organisation

The pages are written for a bank but name no real systems. Words such as "the service
catalog", "the internal SDK bundle", `bank-ai-sdk`, group names like
`ai-knowledge-base-readers`, the Atlassian keys `AIKB`, and every
`video.internal.example` link are placeholders. Replace them with your own before the
first cohort reads this; the [content standards](../governance/content-standards.md) say
which pages carry tested code and which are illustrative.

## Who owns this

The AI Platform Enablement team owns onboarding content. Every page here is reviewed at
least every 90 days; the [librarian agent](../governance/librarian-agent.md) flags anything
older than that for its owner.
