# Integrations

How this knowledge base connects to the systems people already use.

- [Atlassian (Confluence and Jira)](atlassian.md) — pages mirrored to Confluence for
  readers who live there, and Jira issues for findings that need an owner.
- [Platform integration](platform.md) — the API, console and container the AI Platform
  hosts, and how to mount the router inside another application.
- [The console for readers](console.md) — sign-in with the organisation's identity
  provider, reading progress, personas, the librarian chat and its explain / elaborate /
  quiz actions, and what each of them stores.

Integrations are read-mostly by design: the knowledge base in source control is the
source of truth, and every write to an external system goes through the same permission
gate as the librarian's page edits.
