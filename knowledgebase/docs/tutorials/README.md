# Tutorials

Hands-on, in order. Each takes under an hour on the paved Python stack and ends with
something you can show. All examples use the internal SDK bundle and the gateway; no
vendor keys are needed or issued.

| # | Tutorial | You will have |
| --- | --- | --- |
| 1 | [Your first model call](01-first-call.md) | A script that calls the gateway with the right headers and reads its own log entry |
| 2 | [Tool use](02-tool-use.md) | A model that calls one of your functions with validated arguments |
| 3 | [An agent with the Claude Agent SDK](03-agent-sdk.md) | A small agent with a permission gate, dry-run mode and an audit trail |
| 4 | [RAG basics](04-rag-basics.md) | A grounded Q&A loop with citations over a sample corpus |
| 5 | [Evaluations](05-evaluations.md) | An evaluation set and runner wired into CI |

Prerequisites: [Day one](../onboarding/day-one.md) access and workstation setup.
