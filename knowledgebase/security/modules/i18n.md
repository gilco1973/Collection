# Security review sheet: Content translation

| | |
| --- | --- |
| Module id | `i18n` |
| Kind | backend |
| Code | `kb_librarian/i18n/` (`translate.py`, `sync.py`, `localize.py`), `kb_librarian/cli_translate.py` |
| Tests | `tests/test_i18n.py` |
| Depends on | claude-agent-sdk, `actions.py` |

## Purpose

- `localize(catalog, docs_root, lang)`: a read-only view of the catalog with translated
  titles/bodies from `docs/i18n/<lang>/...` substituted where present (used by the API).
- `translate_markdown`: one-shot machine translation of a page via the Agent SDK (no tools).
- `sync`: the nightly job — hashes each page, translates new/changed ones, writes through the
  `ActionLog` (dry-run unless `KB_ALLOW_LIVE=true` and `--live`), keeps a manifest at
  `docs/i18n/.state.json`.

## Entry points

`kb-librarian translate sync [--live] [--languages]`, `localize`, `translate_markdown`, `sync`.

## Trust boundaries

- `lang` reaches `localize` only after `AppState.catalog_for` checked it against
  `config.i18n.languages`, so a request can never name a directory outside `docs/i18n/`.
- The model's reply is untrusted text: parsed for the two markers only, written as Markdown
  content of a page (rendered by the console's non-HTML Markdown renderer).

## Data handled

Page titles and bodies (Internal tier) sent to the model; translations written under
`docs/i18n/`. Frontmatter (owner, status, tags, audience, reviewed) is copied unchanged, never invented.

## Secrets

None. Pages with sensitive findings are skipped by the sync so they are not sent to the model.

## External calls

The model API, one page per call, `max_turns=1`, `tools=[]`, `DISALLOWED_BUILTINS` applied,
`setting_sources=[]`.

## Mutations

Writes under `docs/i18n/<lang>/` through `ActionLog.write_page` (snapshot + action + rollback);
nothing on disk in dry-run. The manifest is updated only for pages actually written.

## Controls in place

- Same live gate as audits (`resolve_dry_run`); the run is a normal report in
  `.librarian/reports/` and each write is `kb-librarian rollback`-able.
- Translation copies are excluded from the English catalog; `localize` ignores symlinks and
  copies without a title.
- Malformed model replies raise `TranslationError` and the page is skipped, not written.

## Residual risks and reviewer attention points

- Machine translation is unreviewed content published to readers; the console labels
  untranslated fallback but not machine origin. Attention point: whether a "machine translated"
  notice is required by policy.
- A translated page inherits the English page's `reviewed` date; freshness is tracked on the
  English source only.

## Reviewer checklist

- [ ] `catalog_for` is the only place `lang` is read from a request.
- [ ] Sync skips sensitive/withheld pages before calling the model.
- [ ] Writes go through `ActionLog`, never `Path.write_text` directly.
