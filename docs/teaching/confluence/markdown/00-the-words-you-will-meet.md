# The words you will meet

*Fifteen terms. Everything else on the hub is ordinary English.*

| Term | What it means |
| --- | --- |
| **The hub** | The website. Four areas along the top: Discover, My workspace, Build, Learn. |
| **The collection** | The shared toolbox of reusable AI building blocks, called components. The hub lists every one of them. |
| **Component** | One building block in one of six kinds: an agent, a harness, a tool, an integration, a pattern, or a skill. |
| **The shelf** | Where a component is once two named people have signed it. "On the shelf" means "safe to reuse". |
| **Sign-off** | A named person's word that they tested and read a component. Two are needed: its owner, and an AI security engineer. |
| **Road** | One of six approved ways to build something, R1 to R6. Picking a road decides which checks apply. |
| **Tier** | How much an action can change. `R` reads. `W1` writes after you confirm. `W2` needs a second person. `MONEY` is refused. |
| **Ladder** | How much autonomy a person or a service is allowed, L0 to L3. A service never acts above the person using it. |
| **Brief** | The one-page form that starts any new use of AI. Six sections, about fifteen minutes. |
| **Assistant** | Something you talk to that reads pages and answers with the page named. It has no tools, so it cannot change anything. |
| **Agent** | Something that can read real systems and propose an action. A write waits for you; money is refused. |
| **Harness** | The loop an agent runs inside. It checks every call the same way; the model cannot skip it. Any brief that names a tool carries it automatically, with the guard, the engine, the chain and ids-only logging. |
| **Knowledge base** | The separate site of practice pages. Every component has a page there too. |
| **Champion** | One engineer per team who carries one initiative and brings the result back to the collection. |
| **The guide** | The spark button at the bottom right of every page. It walks you through the hub and answers from our own pages. |
