# Teaching the Collection

*Every screen, every sentence the hub shows, every flow and every process, explained in plain words. Read it before you teach a cohort, or hand it to someone on their first day.*

| How this guide is written | |

| --- | --- |

| **You see** | The exact words on the screen, shown `like this`, and a real screenshot of the screen at the top of each section. |

| **It means** | What the words are telling you, and what is happening underneath. |

| **Step by step** | Numbered only where the order matters: a flow you follow from first click to last. |

| **The rule behind it** | Notes in blue say why the hub behaves as it does. Nothing here is a side door. |
