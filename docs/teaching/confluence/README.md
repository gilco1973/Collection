# The teaching guide as Confluence pages

One page per chapter of `docs/teaching/teaching-the-collection.html`, ready to upload: an index page and seventeen
chapters, the screenshots and the four process diagrams as attachments, and a Markdown copy of every page for
pasting by hand. Generated by `python3 docs/teaching/build_confluence.py`; a correction goes into the HTML source,
then the build and the upload are run again. Nothing here is edited by hand.

| What | Where |
|---|---|
| The pages, Confluence storage format (what the REST API and the editor take) | `pages/index.xml`, `pages/01-signing-in.xml` … `pages/16-a-45-minute-first-lesson.xml` |
| The images each page attaches | `attachments/<page>/…` (JPEG screenshots, PNG diagrams) |
| The same pages as Markdown | `markdown/index.md`, `markdown/01-signing-in.md` … |
| The manifest: order, titles, files, attachments | `pages.json` |
| The uploader | `upload.py` (standard library only) |

## Upload with the script (recommended)

The script needs a Confluence account that may create pages and attachments in the space. Nothing is stored;
the credentials are read from the environment for the one run.

```sh
# Confluence Cloud: your account's e-mail and an API token (Atlassian account settings → Security → API tokens)
export CONFLUENCE_EMAIL=you@example.com CONFLUENCE_API_TOKEN=YOUR_API_TOKEN
python3 upload.py --base https://your-site.example.net/wiki --space DOCS --parent-id 123456

# Confluence Server / Data Center: a personal access token; the base has no /wiki
export CONFLUENCE_TOKEN=YOUR_PERSONAL_ACCESS_TOKEN
python3 upload.py --base https://confluence.example.net --space DOCS --parent-id 123456
```

- `--space` is the space key (the short code in the space's address). `--parent-id` is the id of the page the
  guide goes under (the number in the page's address, or in Page information); leave it out for the space root.
- `--dry-run` prints what would be created or updated and sends nothing but the page lookups.
- `--title-prefix "AI hub: "` when the space already has pages with these titles; keep it the same on every run.
- Run it again after a correction: pages are updated in place with a new version, attachments whose bytes changed
  are replaced, and pages that did not change are left alone (each page carries a content property with the hash
  of what it was last given). Confluence titles are unique within a space, which is how a page is found again.
- Every line of output names the page, what happened (`created`, `updated`, `unchanged`) and its link. A failure
  names the page and the HTTP status; fix the cause and run again, the pages already up are not uploaded twice.

## Upload by hand

For a space where the API is closed, each page is one paste:

1. Create a page with the chapter's title (from `pages.json`), under an index page named "Teaching the Collection".
2. Cloud: Insert (`/`) → Markup → Markdown, paste the chapter's `markdown/*.md`. Server / Data Center: Insert →
   Markup → Confluence Wiki is the only choice; paste the `pages/*.xml` through the Source Editor instead if the
   space has it, or paste the Markdown into a Markdown macro.
3. Attach the images from the chapter's `attachments/` folder, then place them where the page shows an image
   reference (the Markdown links name the file).

## What became what

The page's constructs are mapped to what Confluence keeps, so no styling is lost silently:

| In the guide | On the Confluence page |
|---|---|
| Chapter heading and its one-line subtitle | Page title; the subtitle as the first line in italics |
| On-screen text `like this` | `code` |
| Chips (R, W1, W2, MONEY, GA, preview …) | Status lozenges, coloured as on the page (grey, yellow, red, purple, green, blue) |
| "You see / It means" tables, the glossary, the lesson plan | Tables |
| Numbered flows with the reason under each step | Numbered lists, the reason on a second line |
| Blue, amber and green notes | Info, warning and tip panels |
| Cards (the six sections, the sign-off roles, the three paths) | A heading and its text or list |
| Commands | Code blocks |
| Screenshots | JPEG attachments, shown at 900 px |
| The four process pictures (Mermaid) | PNG attachments drawn from the same source, with the Mermaid source in a collapsed block under each |
| The contents list | The index page's list of child pages |
